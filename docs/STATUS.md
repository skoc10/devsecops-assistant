## Faz durumu (plana göre)

- **Faz 0** (WP1–WP8): tamam; gerçek Cursor SDK ve gerçek model sağlayıcılarıyla elle kabul **yapılmadı**.
- **Faz 1a**: Terminal Service + kabuk/SQL sınıflayıcı, onay kapısı v0, GitHub Actions/SCM okuma, PostgreSQL reader + doktor, `timeline.build`, skill kayıt defteri, `ops explain-policy` — **tamam** (yukarıdaki tablo).
  - **Faz 1 artıkları — hepsi yapıldı:** Anthropic yerel sağlayıcısı (`cache_control` + `effort` + `providerData`), `egress: local-only` kipi, karantina özetleyici (varsayılan KAPALI; log/olay araçları), `ops replay` (eylem çizelgesi + politika what-if; konuşma yeniden oynatma DEĞİL), runbook → plan (`runbook.list|plan|run`), tam skill linter (`ops skill lint`), skill'e bağlı model kademesi (opt-in, varsayılan kapalı).

İnceleme aynı zamanda depodaki **görünmez Unicode karakterlerini** (kaynakta ham bidi/BOM) ortaya çıkardı: hepsi `\uXXXX` kaçışlarına çevrildi; `skills/generic-diagnosis` içindeki yumuşak tireler silindi. ## DevSecOps / ürün mimarisi incelemesi (2026-10-25)

Tüm kod tabanı (PEP/politika, sırlar/kripto/denetim, sandbox/çalıştırma, ağ adapter'ları, CLI/daemon/skill) beş paralel saldırgan inceleme koluyla tarandı; her bulgu ayrıca doğrulandı, düzeltildi ve **eski kodda kırılan** regresyon testiyle kilitlendi (`core/test/devsecops-review.test.ts` ve ilgili paket testleri). Satır düzeyindeki ayrıntılar yukarıdaki tabloya işlendi. Öne çıkanlar:

- **Yüksek:** model kontrollü `select` ile PEP sürecinde prototip kirletme (denetim reddini bastırabiliyordu); `WHERE 1=1` ile tüm tabloyu `mutate` sınıfında silme; ask kuralının dar allow'a ezdirilmesi (deny>ask>allow ihlali); eşzamanlı onay isteklerinin TTY'de karışması ve bütçeyi atlaması; adapter hata metninin taint/zarf dışında kalması; harf duyarsız dosya sisteminde CI yazma yasağının (`.GitHub/workflows`) atlatılması; düşmanca kubeconfig'in yerel dosyayı (`tokenFile: ../.vault-token`) kasaya alıp kendi sunucusuna göndermesi; eşzamanlı yazıcıların denetim zincirini çatallayıp kurulumu kalıcı kilitlemesi.
- **Orta:** MAC'siz çapa; paralel/hatalı çağrılarla çağrı bütçesinin atlanması; local-only'nin karantina özetleyicisinde çekirdekte uygulanmaması; `OPS_PROVIDER_ZONE=local` ile bulut ucun yerel sayılması; kökensiz çıktılarla (`json_agg(c)`, `c::text`, UNION) maskeli sütun sızıntısı; DB hata satırıyla hücre değeri sızıntısı; uzun `OPS_HOME` ile soketin 0700 dizin dışına kesik adla bağlanması; `OPS_HOME` sahiplik/izin denetiminin olmaması.
- **Düşük:** break-glass süresinin yeniden önizleme sırasında dolması; USING/NATURAL JOIN ile maskeli sütun oracle'ı; ikinci daemon'un soketi devralması; opsd'de satır sonu beklenen bayt sınırı; parola dosyasının symlink/sahip denetimi; kasa/profil/çalışma alanı/politika geçici dosyalarının symlink izlemesi; linter'da tek varyasyon seçicisi/boş glif/benzer harf; Ctrl-C'nin takılmış turu kesememesi; boş dosyaların yamadan düşmesi.
- **CI/tedarik zinciri:** eylemler SHA ile sabit, Node 24 tabanlı sürümler, `ubuntu-24.04`, atlanan test kapısı, CodeQL, `pnpm audit`, Dependabot, pnpm `minimumReleaseAge`/`trustPolicy`/`strictDepBuilds`/`blockExoticSubdeps`.

**Açık kalanlar (bilinçli, ayrı iş):** macOS seatbelt profilinin yeniden tasarımı (yerine VM yolu seçildi, ADR-0011); loopback vekilinin `local` sayılması (kullanıcı beyanı); exec kimlik eklentisi ikilisinin PATH'ten ad ile çözülmesi (TOFU hash pini; `OPS_TOOL_DIRS` ile sınırlanmalı); `OPS_PROVIDER_BASE_URL`'in sağlayıcılar arasında paylaşılması; `ops replay --policy` what-if'inin insan reddini görmemesi (doğrulanmadı); pip bağımlılıklarının hash'li kilitlenmemesi.

## Bilinen eksikler ve belgelenmiş sınırlar

- Gerçek Cursor SDK spike'ı (§6.4-11) geçerli bir Cursor API anahtarı ve hedef işletim sistemi gerektirir; otomatik testler sahte (mock) SDK ile koşar.
- OS sandbox: Linux'ta bubblewrap ile GERÇEK izolasyon testleri koşar (CI'da kurulur; atlanan test CI'ı düşürür). macOS'ta seatbelt çalışmaz; sandbox gerektiren araçlar yalnız `ops vm up` ile açılan Linux VM'inde (bubblewrap) çalışır ([ADR-0011](adr/0011-macos-vm-sandbox.md)); VM kapalıyken fail-closed. VM takımı CI'da koşmaz (`pnpm test:vm`, yerel). Cursor çalışma zamanı ve exec kimlik eklentileri VM kipinde kapalıdır. Windows desteklenmez (Faz 3).

- Lisans henüz seçilmedi (`UNLICENSED`); depo sahibi karar verecek.
