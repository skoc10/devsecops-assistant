# Tehdit modeli

## 9. Tehdit modeli

Varlıklar: kasadaki kimlikler; hedef sistemlerin bütünlüğü; hassas veri (log/DB/konfig); denetim izi; kullanıcı güveni. Saldırgan modelleri: (a) enjekte edilmiş içerik (log, issue, PR, commit mesajı, DB hücresi, skill, MCP açıklaması), (b) hatalı/halüsinasyon yapan model, (c) güvenilmeyen model sağlayıcı/ajan çalışma zamanı, (d) aynı makinedeki başka süreç, (e) dikkati dağılmış / yorgun kullanıcı.

**Faz notları (D13):** PEP, denetim, redaksiyon, kasa/broker, k8s okuma, taint etiketleri: **Faz 0**. Terminal Service + kabuk sınıflayıcı + OS sandbox'lı `shell.run`, onay kapısı v0 (TTY, eylem hash'i), genel `egress: local-only`, SQL sınıflayıcı, DB reader, taint tabanlı `ask`: **Faz 1**. Tam onay kapısı (diff, bütçe, ortam adı yazdırma), yazma araçları, break-glass: **Faz 2**. Faz 0'da `ask` kararı = `deny` (gerekçe kodu ile).

**Kapsam dışı ve kalan riskler (açıkça):** aynı UID'de ptrace/bellek okuyabilen zararlı süreç; ele geçirilmiş işletim sistemi/çekirdek veya OS anahtar zinciri; kullanıcının kendi kabuğunda/ortamında duran kimlikler (yalnız uyarı); model sağlayıcıda saklama/eğitim politikaları (kullanıcı seçer; `trust_zone` + redaksiyon azaltır); kullanıcının bilerek yaptığı gevşetmeler (tavan yükseltme, pin kapatma); hedef sistemlerin kendi zafiyetleri.
